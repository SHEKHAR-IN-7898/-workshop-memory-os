# Workshop Memory OS

AI-powered business memory for automobile workshops.

## Project direction

- Multi-tenant workshop data isolation
- Structured customer, vehicle, service, invoice, technician, and parts records
- Evidence-based AI retrieval over exported business data
- PostgreSQL with Row-Level Security (RLS)
- Integration tests for tenant isolation

## Planned stack

- Node.js + TypeScript
- PostgreSQL
- Prisma
- Vitest

The repository currently contains the architecture scaffold. Database schema, migrations, ingestion, retrieval, and CI will be added incrementally after the application contract is finalized.
